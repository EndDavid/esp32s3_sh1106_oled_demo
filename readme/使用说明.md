## 1. 项目简介

这是一个可以直接编译、烧录、运行的 ESP-IDF 示例工程，用于在 **128×64 的 4 针 I2C OLED** 上显示内容。

功能包括：

- 开机画面（边框 + 大字标题）
- 实时运行时间（秒）
- 当前使用的 I2C 引脚
- 闪烁文字
- 每 10 秒循环一次的进度条

工程自带 OLED 驱动和 5×7 ASCII 字库，**不依赖任何第三方组件**，适合作为学习和二次开发的基础。

支持两种常见 OLED 控制器：

- **SH1106**（1.3 英寸模块最常见，默认）
- **SSD1306**（0.96 英寸模块最常见）

## 2. 硬件准备

| 项目 | 要求 |
| ---- | ---- |
| 开发板 | ESP32-S3（本工程在 N16R8 上验证） |
| 屏幕 | 1.3 英寸、4 针、I2C 接口、128×64 分辨率 |
| 连接线 | 4 根杜邦线（VCC / GND / SCL / SDA） |
| USB 线 | 能传输数据的 USB 线（不能是纯充电线） |
| 电脑 | 已安装 VS Code 和 ESP-IDF 扩展 |

> 4 针 OLED 的丝印顺序不同厂家可能不一样，例如有的是 `GND VCC SCL SDA`，有的是 `VCC GND SCL SDA`。**一定要以模块背面的丝印为准**，不要按线的颜色判断。

## 3. 接线方法

本工程默认接线：

| OLED 引脚 | 接到 ESP32-S3 | 说明 |
| --------- | ------------- | ---- |
| VCC / VDD | **3V3** | 不要接 5V |
| GND | GND | 共地 |
| SCL / SCK | **GPIO9** | I2C 时钟 |
| SDA | **GPIO8** | I2C 数据 |

注意事项：

- 屏幕供电使用 **3.3V**，与 ESP32-S3 的 IO 电平一致。
- 大多数 OLED 模块自带 I2C 上拉电阻；工程内部也开启了弱上拉作为兜底。
- ESP32-S3-N16R8 的 **GPIO33～GPIO37 被 Octal PSRAM 占用**，不要使用。
- 建议使用 GPIO1～GPIO18、GPIO21、GPIO38～GPIO48 中未被板载外设占用的引脚。
- 如果你的接法不是 GPIO8/GPIO9，见 [第 8 节](#8-修改屏幕参数)，不改代码即可修改。

## 5. 第一次运行（图形界面）

### 5.1 打开工程

在 VS Code 中选择 **文件 → 打开文件夹**，打开`esp32s3_sh1106_oled_demo`

### 5.2 设置目标芯片

1. 执行 `Ctrl+Shift+P` → **ESP-IDF: Set Espressif Device Target**。
2. 选择 `esp32s3`。

本工程的 `sdkconfig.defaults` 已默认指定 `esp32s3` 和 16MB Flash，正常情况下无需再改。

### 5.3 选择串口

1. 用 USB 线连接开发板。
2. 点击 VS Code 底部状态栏的串口图标，或执行 **ESP-IDF: Select Port to Use**。
3. 选择开发板对应的 COM 口。

当前板子走的是 **ESP32-S3 原生 USB 口**，枚举为 `COM3`（设备管理器显示 `USB 串行设备`，VID `303A`）。

- 如果使用板载 **UART/COM** 口（CH340、CP210x 等），需要先安装对应驱动。
- 如果拔插后 COM 号变化，重新选择即可。

### 5.4 编译、烧录、查看日志

最简单的做法：

> 执行 **ESP-IDF: Build, Flash and Start a Monitor on Your Device**

也可以分步执行：

1. **ESP-IDF: Build your project** —— 编译。
2. **ESP-IDF: Flash your project** —— 烧录。
3. **ESP-IDF: Monitor your device** —— 打开串口监视器。

监视器退出：`Ctrl+]`；打开菜单：`Ctrl+T`。

### 5.5 正常的启动日志

烧录成功并复位后，串口应打印类似内容：

```text
I (90) oled_demo: OLED demo starting
I (90) oled_demo: I2C0: SDA=GPIO8, SCL=GPIO9, addr=0x3C
I (90) oled: OLED found at 0x3C
```

看到 `OLED found at 0x3C` 说明：

- 屏幕供电正常
- SDA/SCL 接线正确
- I2C 地址正确
- 屏幕已经成功初始化

如果打印 `no ACK from OLED at 0x3C`，见 [第 11 节](#11-常见问题)。

## 6. 屏幕显示内容

### 6.1 开机画面（约 2 秒）

```text
┌──────────────────────────┐
│  ┌────────────────────┐  │
│  │                    │  │
│  │     ESP32-S3       │  │
│  │  ──────────────    │  │
│  │  1.3" OLED DEMO    │  │
│  │    Hello World     │  │
│  │                    │  │
│  └────────────────────┘  │
└──────────────────────────┘
```

标题 `ESP32-S3` 使用 2 倍放大字体。

### 6.2 运行界面

```text
ESP32-S3 OLED DEMO
──────────────────────
Uptime: 12 s
SDA=8  SCL=9
Hello, world! *
┌────────────────────┐
│█████████           │
└────────────────────┘
```

- `Uptime`：程序启动后的秒数。
- `SDA` / `SCL`：编译时配置的引脚编号。
- `*`：每秒闪烁一次。
- 进度条：每 10 秒走满一次，然后重新开始。

程序会一直循环运行，按开发板上的 **RST/EN** 键可重新启动。

## 7. 修改显示内容

所有显示逻辑都在 `main/main.c` 的 `app_main()` 中。修改后重新编译、烧录即可。

### 7.1 显示规则

OLED 驱动采用“显存 + 刷新”的方式：

1. 先用 `oled_clear()` 清空显存；
2. 用各种 `oled_draw_*()` 在显存上绘制；
3. 最后调用 `oled_display()` 一次性刷新到屏幕。

> 只绘制不调用 `oled_display()`，屏幕不会变化。

### 7.2 显示一行自己的文字

```c
oled_clear();
oled_draw_string(0, 0, "Hello ESP32-S3");
oled_draw_string(0, 16, "My first OLED");
oled_display();
```

- `x`、`y` 都是**像素坐标**，不是行号。
- 普通字体每个字符宽 5 像素、步进 6 像素、高 7 像素。
- 屏幕左上角是 `(0, 0)`，右下角是 `(127, 63)`。

### 7.3 显示变量或数字

```c
char line[32];
int count = 42;

snprintf(line, sizeof(line), "Count: %d", count);
oled_draw_string(0, 32, line);
```

提示：整数用 `%d`、无符号数用 `%u`。如果要显示小数，建议先乘以 10 或 100 再转成整数显示，
这样格式更可控，也不会因为屏幕宽度不够而被截断。

### 7.4 放大文字

```c
oled_draw_string_scale(0, 0, "BIG", 2);   // 2 倍
oled_draw_string_scale(0, 24, "HI", 3);   // 3 倍
```

> 放大倍数越大，占用的屏幕空间越大，注意不要超出 128×64。

### 7.5 常用绘图 API

| 函数 | 作用 |
| ---- | ---- |
| `oled_clear()` | 清空显存 |
| `oled_display()` | 把显存刷新到屏幕 |
| `oled_draw_pixel(x, y, on)` | 画一个点 |
| `oled_draw_hline(x, y, w, on)` | 画水平线 |
| `oled_draw_vline(x, y, h, on)` | 画垂直线 |
| `oled_draw_rect(x, y, w, h, on)` | 画矩形边框（不填充） |
| `oled_draw_string(x, y, text)` | 显示 5×7 文本 |
| `oled_draw_string_scale(x, y, text, scale)` | 显示放大文本 |

参数 `on` 为 `true` 表示点亮，`false` 表示熄灭。

### 7.6 修改循环刷新速度

`main.c` 末尾：

```c
vTaskDelay(pdMS_TO_TICKS(200));
```

- 200 表示每 200 毫秒刷新一次。
- 数值越大刷新越慢，数值越小刷新越快（I2C 400kHz 下整屏刷新约 25ms）。

## 8. 修改屏幕参数

执行 **ESP-IDF: SDK Configuration Editor (menuconfig)**，进入：

```text
Component config
  └── OLED Demo Configuration
        ├── OLED I2C SDA GPIO         默认 8
        ├── OLED I2C SCL GPIO         默认 9
        ├── I2C port number           默认 0
        ├── OLED I2C address          默认 0x3C
        ├── I2C clock frequency       默认 400000
        └── OLED controller           默认 SH1106
```

| 配置项 | 说明 |
| ------ | ---- |
| `OLED I2C SDA GPIO` | 屏幕 SDA 实际连接的 GPIO |
| `OLED I2C SCL GPIO` | 屏幕 SCL 实际连接的 GPIO |
| `I2C port number` | 使用 I2C0 或 I2C1，一般保持 0 |
| `OLED I2C address` | 常见 `0x3C`，少数模块是 `0x3D` |
| `I2C clock frequency` | 默认 400kHz；接线较长或干扰大时可降到 100kHz |
| `OLED controller` | 1.3 寸通常 `SH1106`，0.96 寸通常 `SSD1306` |

保存并退出后，重新编译、烧录。

> 修改配置后如果屏幕显示异常，优先检查这两项：
> 1. 控制器型号是否选对；
> 2. I2C 地址是否为 `0x3C` 或 `0x3D`。

## 9. 命令行方式编译烧录

除了 VS Code 图形界面，也可以使用 PowerShell。

### 9.1 一次性加载 ESP-IDF 环境

```powershell
$env:IDF_TOOLS_PATH = 'C:\Espressif'
. 'D:\Espressif\.espressif\v6.1\esp-idf\export.ps1'
cd esp32s3_sh1106_oled_demo
```

每次新开终端都需要先执行上面三行。

### 9.2 常用命令

```powershell
idf.py build                 # 编译
idf.py -p COM3 flash         # 烧录
idf.py -p COM3 monitor       # 打开监视器（Ctrl+] 退出）
idf.py -p COM3 flash monitor # 烧录后立即监视
idf.py menuconfig            # 图形化配置
idf.py fullclean             # 彻底清理编译产物
idf.py size                  # 查看固件大小
```

### 9.3 重新完整编译

如果修改了 `sdkconfig.defaults` 或出现奇怪的编译问题：

```powershell
Remove-Item .\sdkconfig -ErrorAction SilentlyContinue
idf.py fullclean
idf.py build
```

> 删除 `sdkconfig` 后，工程会按 `sdkconfig.defaults` 重新生成配置。

```text
oled_demo/
├── CMakeLists.txt            # 工程入口
├── sdkconfig.defaults        # 默认配置：esp32s3、16MB Flash、USB 控制台
├── sdkconfig                 # 实际配置（由 idf.py 生成）
├── README.md                 # 快速上手
├── 使用说明.md               # 本文档
├── .vscode/settings.json     # ESP-IDF 扩展记录的环境
└── main/
    ├── CMakeLists.txt        # 组件依赖：esp_driver_i2c、esp_timer
    ├── Kconfig.projbuild     # menuconfig 配置项定义
    ├── main.c                # 演示程序（显示逻辑）
    ├── oled.c                # OLED 驱动实现
    ├── oled.h                # OLED 驱动接口
    └── font5x7.h             # 5×7 ASCII 字库
```

### 各文件职责

- **`main.c`**：业务逻辑，决定屏幕上显示什么。
- **`oled.c` / `oled.h`**：I2C 通信、显存管理、绘图 API。
- **`font5x7.h`**：字符点阵数据，仅包含可打印 ASCII（0x20～0x7E）。
- **`Kconfig.projbuild`**：把引脚、地址等参数暴露到 menuconfig。
- **`sdkconfig.defaults`**：新工程首次编译时使用的默认值。

> 特别注意：ESP-IDF 6.x 中 `driver/i2c_master.h` 属于 `esp_driver_i2c` 组件，
> `main/CMakeLists.txt` 的 `PRIV_REQUIRES` 必须包含 `esp_driver_i2c`，否则会编译失败。

## 11. 常见问题

### 11.1 屏幕完全不亮

按顺序检查：

1. VCC 是否接 **3V3**，GND 是否接好。
2. SDA/SCL 是否接反（这是最常见的问题）。
3. I2C 地址在 `0x3C` / `0x3D` 之间换一下。
4. 看串口日志是否打印 `OLED found`。

### 11.2 串口打印 `no ACK from OLED`

含义是屏幕上没有应答，可能是：

- 屏幕没有供电；
- SDA/SCL 接反或接触不良；
- 地址不对；
- 屏幕损坏。

### 11.3 屏幕亮了，但是花屏、错位或只显示一半

控制器型号选错了。执行 menuconfig，在 `SH1106` 和 `SSD1306` 之间切换，重新编译烧录。

1.3 寸屏大多使用 **SH1106**；如果选 SH1106 后图像整体偏 2 像素，本驱动已经内置了 2 列偏移补偿。

### 11.4 找不到 COM 口

- 确认 USB 线能传数据。
- 使用 UART 口时，安装 CH340 / CP210x 驱动。
- 使用原生 USB 口时，Windows 10/11 通常会自动识别为 `USB 串行设备`。
- 打开设备管理器查看是否有未知设备或黄色感叹号。

### 11.5 烧录失败 / 连接超时

1. 按住板上的 **BOOT** 键；
2. 点一下 **RST/EN** 键；
3. 松开 BOOT；
4. 重新执行烧录。

同时确认：

- 没有其他程序占用该 COM 口（例如另一个监视器窗口）；
- 选择的 COM 口是否正确；
- USB 线是否可靠。

### 11.6 监视器没有任何输出

本工程已默认把控制台设置为 **USB Serial/JTAG**，适配原生 USB 口：

```text
CONFIG_ESP_CONSOLE_USB_SERIAL_JTAG=y
```

如果你改用板载 UART 口查看日志，请在 menuconfig 中把 Console 改回 `UART0 / Default`，然后重新编译烧录。

### 11.7 COM 口被占用

关闭其他串口监视器、Arduino 串口监视器、Putty 等程序，或重新插拔开发板。

### 11.8 编译提示找不到 `driver/i2c_master.h`

ESP-IDF 版本低于 v5.2，或组件依赖没写对。本工程已在 `main/CMakeLists.txt` 中写入：

```cmake
PRIV_REQUIRES esp_driver_i2c esp_timer
```

请确认使用的是 **ESP-IDF v5.2 及以上**（本工程在 v6.1 验证）。

### 11.9 中文显示成问号

字库只支持 ASCII。`oled_draw_char()` 遇到不支持的字符会显示 `?`。
显示中文需要额外添加中文字模，见下一节。

## 12. 进阶方向

### 12.1 显示中文

需要自己生成中文字模（例如使用 PCtoLCD2002、字模提取工具），再把点阵数据加入工程。
注意中文字符通常为 16×16 或 24×24，显存占用和刷新时间都会增加。

### 12.2 显示图标或图片

可以用取模工具把单色图片转换成字节数组，然后按页写入显存，或增加一个 `oled_draw_bitmap()` 接口。

### 12.3 显示 WiFi 信息

连接 WiFi 后，把 IP 地址、信号强度等通过 `snprintf()` 格式化后显示：

```c
snprintf(line, sizeof(line), "IP: %s", ip_addr);
oled_draw_string(0, 16, line);
```

注意字符串宽度不要超过 21 个字符（128 / 6）。

### 12.4 做成桌面小屏

可以扩展为：

- 时钟 / 日历
- 天气信息
- 电脑硬件监控（通过串口或 WiFi 接收数据）
- 传感器数据显示
